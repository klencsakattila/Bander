Bander API Endpoints Definition

📝 API Endpoints

👤 User Endpoints

POST /user/register
Description: Register a new user

Example:

HTTP Request:
POST /user/register HTTP/1.1 Host: Bander Content-Type: application/json
Request Body:
{ "email": "user@example.com", "password": "securepassword123" }

Example Response (201 Created):

{ "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..." }

📊 Possible Responses:

Status Code Description
201 User registered successfully, returns JWT token
400 Incorrect data entered or request body is missing
409 User with this email already exists
500 Error creating user or server-side error
POST /user/login
Description: Sign in user with email and password

Example:

HTTP Request:
POST /user/login HTTP/1.1 Host: Bander Content-Type: application/json
Request Body:
{ "email": "user@example.com", "password": "securepassword123" }

Example Response (201 Created):

{ "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..." }

📊 Possible Responses:

Status Code Description
201 Sign in successful, returns JWT token
400 Incorrect data entered or request body is missing
401 Incorrect email or password
500 Error during sign in
GET /user/:id
Description: Get user data by ID with band, instruments, and musical styles

Example:

HTTP Request:
GET /user/1 HTTP/1.1 Host: Bander

Example Response (200 OK):

{ "id": 1, "username": "PopcornLover21", "email": "user@example.com", "first_name": "John", "last_name": "Doe", "city": "Budapest", "birth_date": "1990-01-15", "is_admin": 0, "band": { "id": 1, "name": "The Band" }, "instruments": [ { "id": 1, "name": "Guitar" } ], "styles": [ { "id": 1, "name": "Rock" } ] }

📊 Possible Responses:

Status Code Description
200 Successful query, returns user data with related info
400 Id is not valid
404 User not found
500 Error fetching user data
GET /user/limit/:limit[/:offset]
Description: Get limited list of users with pagination

Example:

HTTP Request:
GET /user/limit/10 HTTP/1.1 Host: Bander OR with offset: GET /user/limit/10/20 HTTP/1.1 Host: Bander

Example Response (200 OK):

[ { "id": 1, "username": "user1", "email": "user1@example.com", "first_name": "John" } ]

📊 Possible Responses:

Status Code Description
200 Successful query, returns array of users
500 Error fetching users
PATCH /user/:id
Description: Update user data

Example:

HTTP Request:
PATCH /user/1 HTTP/1.1 Host: Bander Content-Type: application/json
Request Body:
{ "username": "NewUsername", "first_name": "John", "last_name": "Doe" }

📊 Possible Responses:

Status Code Description
200 User updated successfully
404 User not found
500 Error updating user
POST /user/:id/profile-image
Description: Upload user profile image

Example:

HTTP Request:
POST /user/1/profile-image HTTP/1.1 Host: Bander Content-Type: multipart/form-data file: [binary image data]

📊 Possible Responses:

Status Code Description
200 Image uploaded successfully
404 User not found
500 Error uploading image
DELETE /user/:id
Description: Delete user by ID

Example:

HTTP Request:
DELETE /user/1 HTTP/1.1 Host: Bander

📊 Possible Responses:

Status Code Description
200 User deleted successfully
404 User not found
500 Error deleting user

Status Code Description

HTTP Request:
POST /genre HTTP/1.1 Host: Bander Content-Type: application/json Authorization: Bearer [JWT_TOKEN]

Status Code Description

400 Genre name is required

💬 Thread Endpoints

GET /thread/:id/:numberofmessages
Description: Get thread with users and messages

Example:

HTTP Request:
GET /thread/1/20 HTTP/1.1 Host: Bander

Example Response (200 OK):

{ "thread": { "id": 1, "created_at": "2024-01-15T10:30:00Z" }, "users": [ { "id": 1, "username": "user1" } ], "messages": [ { "id": 1, "sender_id": 1, "message": "Hello!" } ] }

📊 Possible Responses:

Status Code Description
200 Successful query, returns thread with users and messages
400 Invalid thread id
404 Thread not found
500 Error fetching thread
POST /thread
Description: Create a new thread between two users

Example:

HTTP Request:
POST /thread HTTP/1.1 Host: Bander Content-Type: application/json
Request Body:
{ "user1_id": 1, "user2_id": 2 }

📊 Possible Responses:

Status Code Description
200 Thread already exists, returns existing thread
201 Thread created successfully
400 Invalid user ids or users must be different
404 User not found
500 Error creating thread

📬 Message Endpoints

POST /message
Description: Create a new message in a thread

Example:

HTTP Request:
POST /message HTTP/1.1 Host: Bander Content-Type: application/json
Request Body:
{ "thread_id": 1, "sender_id": 1, "message": "Hello, this is my message!" }

📊 Possible Responses:

Status Code Description
201 Message created successfully
400 Invalid input or missing required fields
403 Sender is not in this thread
404 Thread or sender not found
500 Error creating message
DELETE /message/:id
Description: Delete a message by ID

Example:

HTTP Request:
DELETE /message/1 HTTP/1.1 Host: Bander

📊 Possible Responses:

Status Code Description
200 Message deleted successfully
400 Invalid message id
404 Message not found
500 Error deleting message
